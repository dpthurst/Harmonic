\section{Map $(1+z^2)/(1-z^2)$}
For the map $z \mapsto \frac{1+z^2}{1-z^2}$. Values of $\Emb$ for
$f^{(n)}$, using the theta graph with the given parameter. A middle
edge parameter of $0$ means that it degenerates to a bouquet, and a
negative middle edge parameter means we go to the corresponding
barbell graph.

The actual limit is $2^{-1/3} \approx 0.793701$.

\section{Slit Latt\'es}
For the map $z \mapsto \dfrac{z^2(z-1)}{(z-1/3)^3}$. This is a slit
Latt\'es example; it is degree 3, with a Sierpinski carpet Julia set
with 3 post-critical points.

\section{Quadratic Sierpinski carpet}
\label{sec:quadratic-carpet}
This is the unique quadratic rational map with 4 post-critical points
whose Julia set is a Sierpinski carpet. In Kevin Pilgrim's census, it
is \#3.2.
